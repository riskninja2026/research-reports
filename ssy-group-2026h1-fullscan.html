三十秒版本 · 先看结论

如果只读一屏，先抓住这五件事

  • 它是谁：一家以大容量静脉输液为核心、同时经营安瓿注射液、原料药、口服制剂及医用材料的制药集团；“静脉输液及其他”占本期外部收入95%。
  • 本期成绩：港元收入23.61亿、归母净利润3.20亿，同比分别增长9.9%和13.0%；输液放量是最扎实的经营证据，非PVC软袋及直立袋贡献超过全部收入增量。
  • 核心矛盾：毛利率下降0.27个百分点，但经营利润率提高1.59个百分点。利润弹性主要由销售费用节省和损益表研发费用下降形成，而总研发投入也下降20.4%、资本化率上升6.81个百分点。
  • 最容易踩的坑：公司披露的是累计2026H1，不是独立Q2；港元收入增长9.9%也不等于本币经营增长，管理层披露的人民币收入只增长约5%。当前公告没有现金流量表。
  • 结论：中性。HK$2.705位于本报告HK$2.50—2.95的基准价值带，12倍P/E下已隐含约6.65亿港元归母利润，接近2027年基准情景；安全边际有限。
入门 · 三分钟看懂这门生意

石四药把注册、制造与医院准入串成一条产业链

公司的主要利润池仍是输液与其他制剂。原料药既可对外销售，也为部分制剂提供一体化供应；药品获批后还要经历挂网、集采、医院准入和实际采购，监管进度不等于已经形成收入。

环节 1
研发与注册

仿制药、复杂制剂和早期创新项目产生研发支出；部分符合条件的开发成本被资本化。

环节 2
规模化生产

输液包装结构、产能利用、原料自给和质量控制决定制造成本与毛利。

环节 3
招采与销售

集采以价格换采购量，基药目录提升准入机会；真正变现仍取决于执行价、约定量和终端采购。

环节 4
现金与分配

应收、库存、资本开支和借款决定利润能留下多少现金，再由股息、回购与奖励计划分配。

新读者要先记住三条边界。第一，集团有“静脉输液及其他”和“医用材料及相关产品”两个可报告分部，但没有披露每个具体药品的利润。第二，2022年收购友谊化工造成原料药和合并范围断点。第三，主席曲继广兼任行政总裁；四川科伦既是约23%的重要股东和同业公司，也有董事席位并与集团发生材料、制造和研发交易。

白话解读

五年表讲的是利润平台被打断：2025年不是正常年份里的一点波动，而是毛利率、ROE和ROIC同时跌到五年低点。2026H1的增长说明低谷后已经回升，不能说明旧平台已经回来。

本期增长也很集中。非PVC软袋及直立袋新增收入超过集团全部增量，口服制剂下降又抵消约六成增量。因此要验证的不是“收入有没有增长”，而是输液放量能否跨期、口服能否止跌，以及这些增长能否变成现金。

增长质量 · 利润桥 · 币种

输液量增可信，利润率扩张却主要来自费用端

公司公告显示输液销量和收入均实现双位数增长，收入达到14.87亿港元。收入除以销量得到的港元单位收入代理为正，但同时混合包装、产品、地区和汇率，不能称为人民币提价。管理层披露人民币总收入约20.75亿元、只增长约5%；两种币种的收入增速相差约4.9个百分点。若用“（1＋港元增速）／（1＋人民币增速）−1”观察，隐含折算乘数代理约为+4.7%，不是公司披露的固定汇率桥。

白话解读

输液销量确实在恢复，这是本期最强的证据。但毛利率没有跟着上升，经营利润率变好主要因为销售和损益表研发费用占收入更低。

量增证明工厂重新出货，不自动证明每一瓶更赚钱。要把“恢复”升级成“质量改善”，还需要看到毛利率稳定、费用节省不伤害研发，以及全年经营现金流兑现。

“获批”像拿到入场券，不等于比赛已经赢了。石四药已证明能持续把产品推进到监管节点；下一步要看复杂制剂是否真正挂网、进入医院并产生可见毛利。与此同时，本期利润受益于费用化研发下降，批件多不能替代对研发总额和资本化率的检查。

海外业务 · 地域结构 · 汇率

海外连续快于国内，但收入增长还没有利润与现金画像

已建立的证据

五年海外收入方向持续向上，本期增速再次超过国内；注册与出口数量提供了渠道扩张的前置证据。

仍缺少的经济性

没有不变汇率收入桥，也没有海外利润和现金。汇率已同时影响港元收入与财务费用，不能把报表增长直接当作本地需求。

白话解读

海外收入像新增的一条水管，流量确实越来越大；但公司没有告诉我们这条水管的成本、占用资金和最后留下的现金。因此海外是增长证据，不是独立估值单元。

现金流 · 资产负债 · 股东回报

资产负债表仍可承受，现金转换必须等完整中报

风险与证伪

四个暴露决定修复能否穿过下一个报告期

一 · 量增但毛利不增

输液放量已经成立，但综合毛利率仍下降；集采执行、包装结构和汇率都可能让销量与单位经济继续分叉。

二 · 费用支撑利润

经营利润率提升依赖销售费用率下降和费用化研发减少；若费用回升或资本化项目减值，利润弹性可能回吐。

三 · 现金与浮息负债

当前公告没有现金流量表，集团仍处于净负债且借款大部分浮息；应收与库存继续占用资金。

四 · 批件与治理转化

产品获批、拟中选和奖励池购股都缺少经济结果；四川科伦的多重角色又提高对关联定价透明度的要求。

白话解读

这四类风险不是互相独立：集采可能推动销量、压低价格、减少销售费用并增加应收，最后同时进入毛利、费用和现金。只看其中一个指标容易得出过早结论，必须用同一期间的量、毛利和现金一起裁决。

最终判断

值得跟踪的低谷修复，还不是有充分安全垫的价值股

投资判断：中性。控制性论点是“输液放量是真的，低估值还需要证明”。本期提供了销量和利润同比修复，但毛利、研发投入、现金流与现价隐含预期尚未形成同方向证据。主估值总区间HK$1.62—3.95，现价处于基准区间内；数据置信度为中等。

最强牛方

高端输液包装占比提升、海外增长、密集批件与集采准入可能共同恢复产能利用和ROE；若复杂制剂商业化快于预期，当前P/E会被快速增长的利润分母压低。

最强熊方

量增没有带来毛利率上升，口服制剂大跌，利润扩张又依赖费用收缩；在现金流缺失和净负债存在时，恢复可能只停留在低基数同比。

如何裁决

把输液销量、集团毛利率、口服收入、完整现金转换和净负债放在同一期间检查；批件和拟中选只作领先指标。

明确失效线

若2026H2收入同比不增长、输液销量增速降至个位数且集团毛利率不高于41%，或FY2026 FCF代理/归母净利润低于55%、含租赁净负债不降，任一项都要求下修基准情景。55%是模型阈值，不是公司指引。

术语白话解释
H1 / H2 / FY / 独立Q2上半年 / 下半年 / 全年 / 只含4月至6月的第二季度。石四药本次只披露2026H1。
可报告分部管理层用来分配资源并单独披露结果的会计业务单元；具体产品收入不等于分部利润。
毛利率 / 经营利润率毛利 / 经营利润各自占收入的比例；前者更接近产品单位经济，后者还受费用与其他收益影响。
归母净利润扣除非控股股东应占部分后，归属于上市公司股东的净利润。
EPS / BVPS每股盈利 / 每股净资产；EPS使用期间加权股数，BVPS和估值还要明确是否扣除库存股。
ROE / ROIC净利润相对平均归母权益的回报 / 税后经营利润相对平均投入资本的分析回报。
CAGR复合年均增速，把起点到终点的累计变化折成每年的复合速度。
LTM最近十二个月。本报告用2025全年加2026H1、再减2025H1。
OCF / CAPEX / FCF代理经营现金流 / 资本开支 / OCF减广义现金再投资的分析近似值。
ASP / 单位收入代理平均售价 / 用收入除以销量的近似数；都可能混合规格、产品、地区和汇率。
资本化研发符合会计条件后暂列为资产的开发支出，不立即进入损益；未来可能摊销或减值。
一致性评价证明仿制药质量和疗效与参比制剂相符的监管评价，常是招采准入条件之一。
CDE / IND / PCC国家药监局药品审评中心 / 临床试验申请 / 临床前候选化合物；三者代表不同研发阶段。
拟中选 / 集采拟进入集中采购结果 / 以集中采购换取约定量；拟中选不等于最终合同和已实现收入。
基药目录国家基本药物范围，是医疗机构配备和优先使用的重要依据，不是独家采购承诺。

P/B LF / Gordon P/B股价相对最新账面净资产的倍数 / 用可持续ROE、股权成本与长期增长解释P/B的关系。
