三十秒版本 · 先看结论

如果只读一屏，读这里

  • 它是谁：格力以消费电器为利润核心，空调是主导品类，同时经营冰洗及生活电器、工业制品与绿色能源、智能装备。它依靠自研制造、品牌和经销网络赚钱；合并财务公司后，集团现金流比普通制造企业更难直接阅读。
  • 本期成绩：2026H1（上半年）收入和归母净利润都下降；用 H1 累计减Q1（一季度）累计得到的单二季度（推算）中，收入、归母净利润和经营现金流（OCF）的同比降幅均深于 H1 累计，其中 OCF 降幅最大。单季数字是分析推算，不是公司单独披露。
  • 核心张力：低毛利其他业务收缩确实放大了表面收入降幅，但消费电器的毛利额也在下降。已披露的智能装备收入规模仍小，数据中心液冷（用液体给服务器降温）与碳化硅功率芯片又缺独立经济数据，尚无证据证明新业务足以接棒。换句话说，报表在“瘦身”，主业却还没有重新增长。
  • 一个容易踩的坑：H1 低毛利其他业务权重下降可以支撑合并毛利率，推算 Q2 销售及研发费用下降则支持营业利润率；公司没有披露 Q2 产品组合，两条机制都不能证明空调已经提价成功。账上货币资金也不等于全部可以立即分给股东。
  • 结论：收益型逻辑尚可，增长型重估未成立。前者指回报主要依赖分红，后者指增长恢复后市场愿意给更高估值。市场价约39元（2026-08-28盘中），本报告基准情景价值带为36–47元；上行要靠终端需求、主营毛利、现金转换（利润经现金流调整后能留下多少经营现金；这里只是分析代理，不等于可直接分配），以及回购注销减去激励放股后的净注销与回购价格共同验证。
入门 · 三分钟看懂这门生意

格力赚的是制造、品牌和渠道的钱

把格力看成一条从零部件到消费者的家电链条，会比只把它看成“空调股”更准确。钱和风险大致按下面四个环节流动：

环节 1
采购与自制零部件

铜、铝、塑料、压缩机和电子元件构成主要成本驱动。原料上涨能否转嫁，取决于品牌、产品结构和行业价格竞争。

环节 2
制造并形成产品组合

消费电器贡献主要利润，空调是核心品类；冰洗和生活电器扩充家庭场景，工业制品、绿色能源与智能装备仍在培育。公司没有单列空调利润。

环节 3
经销、直营、工程与出口

工厂向渠道发货是sell-in，消费者真正买走是sell-through；两者之间的库存和返利是判断收入质量的关键因素。

环节 4
两支现金再分配

家电业务由经销商和工程客户以预付款、现金、票据或赊销结算；财务公司的存款、贷款本金和保证金则另行进出。两支资金都会进入合并报表，再形成存款、金融资产、股息、回购或投资，所以报表 OCF 不等于工业主业可分配现金。

再记三件结构性事实。第一，格力是深交所A股公司，公司披露为无控股股东、无实际控制人，但第一大股东及一致行动人持股集中且存在质押。第二，公司把消费电器合并披露，没有单列空调、冰箱和洗衣机的收入与利润，因此不能从集团毛利率反推某一品类的价格。第三，带虚线下划线的术语可在文末「名词速查」找到。

行业背景可以压缩成一句话：白色家电需求已以存量替换为主，但仍有新增家庭、品类渗透和区域差异；需求还会受天气、地产后周期、以旧换新补贴和渠道库存影响，铜等原材料又影响成本。对格力而言，真正的问题不是“空调还卖不卖”，而是成熟主业能否在守住份额的同时守住单位利润，并让新业务形成可核验的第二增长来源。

白话解读

报表收入下降并不全是坏事：公司把低毛利其他业务收缩描述为主动优化，报表可以验证的是这部分收入确实大幅减少、对毛利影响有限。但不能把这理解成“核心业务没问题”。真正决定价值的消费电器仍在少赚毛利；智能装备虽已有收入、但规模仍小，液冷和碳化硅则只有技术、项目或管理层口径，缺少独立收入、利润和回款数据。因此只能说尚无证据证明新业务足以接棒。

估值上的处理很简单：已经进入合并利润的业务照常算，只有技术叙事、没有经济数据的业务不给额外价值。

品牌与渠道 · 行业环境 · 海外业务 · 管理层问答

国内守住了收入，却没有守住单位经济

国内主营收入方向强于行业销量，但产品、价格和渠道组合没有拆开，不能由此直接推断份额上升；可确定的代价是毛利额和毛利率下行。行业需求转弱、铜价上涨和出厂价格仍通缩，使“坚持价格”与“保住份额”难以同时成立。真正需要验证的是终端动销，而非工厂出货或公司库存的单一改善。

外销主营占集团收入逾一成，满足独立海外检视门槛。全品类外销主营收入金额的方向弱于行业空调出口单位数，毛利率却改善，符合管理层“自主品牌和高质量发展”的方向。但产品、金额/数量、地域与汇率口径都不同，这只是风险信号，不能推断份额损失。中东等地缘因素是公司的解释之一；地域收入、恒定汇率增长、海外税负、当地现金贡献与汇回约束均未披露。

盈利能力 · 利润质量

二季度利润率改善，不能等同于核心业务定价权

推算单季毛利率和营业利润率改善，且销售与研发费用明显下降；但公司没有披露单季产品或业务结构，无法将 Q2 毛利率变化精确归因于组合。半年产品表另外显示，消费电器、工业业务和国内主营毛利率都在下降。因此，合并利润率上升可以作为费用纪律证据，却不是品牌提价的充分证明。

白话解读

合并毛利率像“平均分”。当一门分数很低的课程权重被大幅压低，平均分仍可能上升，即使几门权重更大的主课分数下降。H1 业务表可确认低毛利其他业务权重下降，为 H1 合并毛利率提供结构支撑；推算 Q2 的销售及研发费用下降则支持营业利润率。Q2 产品组合未披露，不能把推算 Q2 毛利率改善归因于组合，也不能说所有产品都在改善或都在恶化。

营业利润是税前经营结果之一；交税比例上升后，留给股东的税后利润会下降得更快。这里只能确认推算单季的算术结果，不能确认独立 Q2 税率上升的具体原因。

研发也需区分口径：管理层表列“研发投入”，利润表列“研发费用”，两者并非同一个数字。智能装备已披露收入，液冷也有项目中标；但费用下降是否代表效率提高，仍需订单金额/在手量、分产品收入、毛利、回款和资本回报验证，这些量化数据尚未完整披露。

白话解读

格力账上“钱很多”是真的，但这些钱有不同身份：有些能立即使用，有些是期限较长的存款，有些被保证金用途限制，还有一部分在财务公司体系里支持客户和供应商融资。把它们全部当成随时可分红的现金，会高估安全垫。

例如，财务公司去年放出一笔贷款、今年收回本金，今年合并经营现金流会机械变好，但家电利润并未因此增加。股息是否可持续，先看正常化后的所有者收益能否覆盖。净注销决定股数是否减少；回购能否增厚每股内在价值，还取决于执行价格和资金成本。授权、执行与注销必须分开。

管理层 · 股权结构 · 公司治理 · 员工持股

白话解读

第一大股东质押属于股东自己的融资，不是格力的公司债务；它不会直接抽走上市公司现金，却可能放大减持、股价和控制安排的尾部风险。由于平仓条件没有披露，不能把“无平仓风险”的陈述当作已经独立验证的事实。

同业 · 股价 · 盈利预测 · 业务组合估值

低预期市盈率背后，是一致预期里的下半年反弹

估值要依次回答四个问题：市场现在付什么价？同业为什么更贵？不同经营情景能支持什么价值？现价又隐含了什么预期？盘中市值约2,164亿元，市盈率（PE）、市净率（PB）和股息率与低增长、高分红的定价解释相符，但这不是市场观点的唯一解释。

第一步
看市场现在付什么价

用最近十二个月利润、净资产和上一财年股息判断当前价格是为盈利、资产还是现金回报买单。

第二步
解释同业折价

只比较业务相近且口径可核验的公司；产品与地区更分散，通常会降低单一品类或市场造成的盈利波动，所以更成熟的多元化企业才可能享有更高倍数，不能把同业倍数直接照搬。

第三步
三种方法互相约束

规范化 PE给稳定盈利定价；所有者收益折现（DCF）检验长期现金；股息折现（DDM）检验收益型底线。三者不机械平均。

第四步
把价值放回现价

用同一种规范化 PE 情景画价格阶梯，再用现金与股息模型检查它是否过于乐观或保守。

条形宽度＝该行价格÷四行最高值；涨跌幅＝情景价格÷市场价−1。三档价值均来自同一套规范化次年市盈率方法，避免把不同估值方法混成一条假精确的曲线。

决策不对3种方法取平均；股息折现给出收益下限，规范化盈利给出基准上端。DCF 的60余元是条件性上行：它要求接近90%的所有者收益转换长期持续，并且留存资金能创造价值。股息反推显示，在接近10%的要求回报率下，当前价格隐含每股分红永续增长约1.7%；市场在定价低增长，不是在定价分红必降。

白话解读

三种方法回答的问题不同。规范化市盈率问“利润恢复后，市场愿意为每一元利润付多少钱”；所有者收益折现问“这些利润最终能变成多少长期现金”；股息折现只问“如果主要靠分红拿回报，现在值多少”。它们不能简单平均，因为对留存现金的处理不同。

现价已经落在本报告基准情景价值带里。本报告的基准情景要求下半年反弹、现金转换和分红同时成立；现价与这种低增长、高分红定价相符，但不能反推出市场只有这一套精确预期。现金折现给出的更高价值只有在留存资金持续创造回报时才成立，不能把它当作无条件目标价。

规范化 PE＝次年情景利润÷当前股本×目标倍数；DCF 折现3年所有者收益与终值，不另加超额现金；DDM＝次年股息÷（股权成本−永续增速）。未披露分部利润和现金，故不制造 SOTP；液冷、芯片等可选项价值为零，直到出现可核验经济数据。

风险预警 · 投资验证 · 多空辩论

最强多头是现金回报，最强空头是增长质量

支持

低毛利其他收入收缩使报表比核心经营看上去更差；国内收入方向强于行业数量，利润率和调整后现金仍足以覆盖高分红。

反对

二季度收入、利润和现金同步转弱，国内毛利率下降，外销收入金额也显著弱于行业出口数量的方向，低倍数可能是增长陷阱而非错价。

替代解释

补贴基数、季节结算、主动守价和海外地缘因素可能造成短期波动；费用纪律与产品结构能继续保护利润。

裁决

观察后续终端销量、主营毛利、合同负债、调整后现金转换与净注销；5项同向改善才支持重估。

白话解读

这份报告的多空分歧不是“格力好不好”，而是“低估值补偿是否足够”。多头相信报表收入被主动瘦身放大、分红可以帮助投资者等待；空头担心成熟主业同时丢掉增长和毛利，所谓便宜只是结构性低增长的正常价格。

最有用的裁决不是再争论品牌，而是等同一组可观察结果：终端需求、主营毛利、正常化现金和净注销能否一起改善。只改善其中一项，仍不足以证明重估。

最终投资建议与操作方案

收益型逻辑可守，增长型重估尚未成立

判断：现价位于上文基准价值带内偏下；格力可作为高现金回报的观察或持有候选，但还不是增长修复已被证实的重估标的。最强的多头替代解释是补贴高基数、季节结算、主动守价和海外地缘因素使二季度只是暂时波动，而费用纪律与高分红可以跨过低谷。

失败边界：若下半年收入与利润反弹没有出现，或全年调整后所有者收益转换率低于 85%，基准情景失效；若现有每股股息难以维持，收益型逻辑也失效。

名词速查 · 快速检索

读懂格力报表和估值需要的词

术语白话解释
H1 / Q1 / Q2 / FY / EH1 是上半年累计；Q1、Q2 是第一、第二季度；FY 是完整财年；年份后的 E 表示机构预测值，不是已经实现的业绩。
归母净利润归属于上市公司股东的净利润，已经扣除子公司少数股东应占部分。
毛利 / 毛利率毛利＝收入减直接营业成本；毛利率＝毛利÷同口径收入。合并毛利率是集团平均值，会受高低毛利业务占比变化影响。
营业利润 / 营业利润率营业利润是营业总收入扣除营业总成本、再计入经营相关收益后的税前结果；营业利润率＝营业利润÷营业收入。
扣非归母 / 非经常项目扣非归母是在归母净利润基础上剔除政府补助、部分投资损益等非经常项目，用来观察更可持续的核心利润。
经营现金流（OCF）经营活动实际流入减流出的现金；格力合并了财务公司，因此客户贷款、存款和保证金也会影响这一数字。
现金转换 / 所有者收益转换率观察会计利润如何近似转成正常化经营现金；本报告的转换率＝调整后所有者收益÷归母净利润。它是分析代理，不等于可直接分配现金。
资本开支（CAPEX）购买厂房、设备、软件等长期资产支付的现金；不等于利润表里的折旧。
简化自由现金流（FCF）本报告用经营现金流减资本开支得到的近似值。它还没有剔除财务公司波动，所以只能作为线索。
所有者收益（owner earnings）本报告在经营现金流基础上，扣除可识别的融资业务释放、非现金薪酬和资本开支，得到正常化经营现金的分析代理；它不是公司披露指标，也不等于可直接分配现金。
EPS每股收益＝归属于普通股股东的利润÷加权平均股数。
ROE本报告财务表口径为归母净利润÷加权平均归母净资产；上半年披露值是半年期回报，不机械年化成全年。
BVPS每股净资产＝期末归母股东权益÷期末股本，是账面价值而不是立即可分配现金。
sell-in / sell-throughsell-in 是公司向经销商发货；sell-through 是经销商真正卖给消费者。前者增长不代表终端需求同步增长。
单位经济 / 终端动销单位经济是每卖一台或一类产品能留下多少毛利；终端动销是消费者实际买走商品，不是厂家向渠道发货。
合同负债公司已收或应收客户对价、但尚欠交货或服务义务的金额。它下降通常意味着预收款缓冲减少，但也会受季节结算影响。
应收款项融资公司持有、通常计划贴现或转让的银行承兑汇票等票据资产；上升说明更多资金被票据占用，但不等于已经坏账。
PPI工业生产者出厂价格指数；低于100表示同口径出厂价同比下降。行业指数不能直接当作格力自己的售价。
套期保值用期货或其他工具对冲铜等原料价格波动；它能缓冲风险，但不保证完全抵消采购成本上涨。
单二季度（推算）用半年累计值减去一季度累计值取得的季度数据。它可以审计算术，但不是公司单独披露口径。
有效税率 / 递延所得税有效税率＝所得税费用÷税前利润；递延所得税反映会计与税务确认时点差异，不一定对应当期实际缴税现金。
财务公司 / 融资业务释放集团内持牌金融机构，会吸收存款并发放贷款；贷款收回或保证金减少会抬高合并 OCF，但不代表家电业务多赚了利润。
现金及现金等价物现金和期限短、流动性强、价值变动风险很低的投资；定期存款、受限保证金和金融资产不能全部自动算入。
权益结算股份支付以股份或股份价值结算的员工激励费用，影响利润但当期通常不直接流出现金，因此现金正常化时单独处理。
LTM / TTM最近十二个月滚动合计，用上一完整财年加本期、减上年同期，减少半年报季节性的干扰。
CAGR复合年均增速，把起点到终点的总变化折算成每年相同的增长率。
PE / PB市盈率是股价÷每股盈利；市净率是股价÷每股净资产。低倍数可能是便宜，也可能在补偿低增长或风险。
规范化 PE先把利润调整到可持续水平，再乘以合理市盈率倍数，避免拿异常高或异常低的一年直接定价。
一致预期 / 2026E多家机构预测的汇总值；2026E 中的 E 表示 estimate（预测）。机构更新时点不同，所以它是锚，不是确定事实。
DCF把未来所有者收益按风险要求折回今天。结果高度依赖现金转换、权益成本和长期增长率。
股权成本 / 要求回报率股东因承担经营和市场风险而要求的年化回报率；假设越高，未来现金折到今天的价值越低。
永续增速 / 终值永续增速是假设显式预测期后现金长期增长的速度；终值是该阶段以后全部现金折算出的价值，通常是 DCF 最敏感部分。
DDM只把未来股息折回今天，适合检查收益型逻辑，不会自动给留存现金高价值。
DPS每股股息。股息率等于每股股息÷股价。
SOTP分部加总估值，先分别估值各业务再相加。格力没有披露足够的分部利润和现金流，本报告不强行使用。
控股股东 / 实际控制人 / 一致行动人控股股东持有多数表决权，或其表决权足以对股东会决议产生控制性影响；实际控制人是最终能支配公司的人；一致行动人约定共同表决。格力披露无前两者，但存在一致行动安排。
质押 / 平仓线股东把股份作为借款担保；股价跌到约定阈值可能触发补仓或处置，这个阈值就是平仓线。它是股东融资风险，不是公司债务。
库存股 / 归属 / 摊销库存股是公司回购但尚未注销或转出的股份；归属是员工满足条件后取得股份；摊销是把激励费用分期计入利润表。
净稀释 / 净注销净稀释看激励放出的股份是否超过注销股份；净注销是注销股份减去激励重新放出的股份，只决定股数方向。是否增厚每股内在价值还取决于回购价格和资金成本。
营运资本存货、应收、预付与应付、合同负债等日常经营资金占用的净变化；释放会短期增加现金，但不能无限重复。
