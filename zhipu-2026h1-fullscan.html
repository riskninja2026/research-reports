三十秒版本 · 先看结论

如果只读一屏，读这里

  • 先校正口径：港交所只披露截至2026年6月30日止六个月的累计业绩，没有独立Q2损益、现金流或资本开支。本报告因此按2026H1分析，不制造单季数字。
  • 它是谁：智谱是一家基础大模型与MaaS公司，既通过云端API/订阅按调用收费，也向企业交付本地化模型与智能体。2026H1云端部署已占收入86.5%，商业模式从项目制明显转向高频调用。
  • 本期拐点：收入9.54亿元（+399.7%），开放平台/API收入8.25亿元（+2,735.7%），云端毛利率由−0.4%升到24.6%。销售营销费用反而下降14.8%，支持“产品拉动”而非单纯买量。
  • 但不是盈利拐点：经营亏损扩大13.0%至21.47亿元，经调整亏损扩大12.1%至19.64亿元。IFRS净亏损收窄12.1%，主要来自投资者金融工具损失减少和联营公司利润增加，而非主营经营转正。
  • 资金不再是短期问题：7月配售净募资313.75亿港元，备考净现金类资产约291.7亿元人民币；但这是研发与亏损的燃料，不是可分红“闲钱”。同时仍有10%股份奖励授权和待审批A股计划。
  • 结论：中性偏谨慎／观望。商业化证据足以提高基本面评价，却不足以支撑HK$1,195的容错率。即使2028年收入做到220亿元、仍给30倍EV/Sales，最大规划摊薄口径的现值约HK$1,039，仍低于现价。
入门 · 三分钟看懂这门生意

把“模型能力”变成“可重复调用”，钱才开始流进来

智谱的核心资产不是一套固定软件，而是一条持续烧钱、持续迭代的基础模型生产线。研发团队训练和强化模型，算力既是研发投入，也是云端服务的直接成本；客户则通过API、订阅、本地化部署和智能体付费。整个商业链条可以拆成四步：

环节 1
训练基础模型

研发费用承担模型、数据、人才和训练基础设施；2026H1研发支出21.31亿元，是收入的223%。

环节 2
云端按使用收费

开放平台按token使用量或订阅期收费，企业和开发者无需自建整套模型系统；这是本期86.5%的收入来源。

环节 3
企业本地交付

模型部署在客户基础设施，按模型规模、算力和实施成本定价；验收确认收入，通常更重交付、波动更大。

环节 4
调用反哺迭代

真实编码与Agent任务能提供反馈轨迹；若调用量扩大、单位推理成本下降，云端毛利才可能继续爬升。

财务报表的正式分部只有云端部署和本地化部署。公告另给出开放平台/API、企业级智能体（Agent）、企业级通用大模型、技术服务四条产品线，它们是管理层拆分，不能冒充IFRS分部。公司2026年1月在香港上市，7月又完成巨额H股配售；今天的投资问题已从“能不能融资”转向“这些资本能不能形成每股价值”。

还要避免一个词义陷阱：API调用可以反复发生，但不等于合同锁定的ARR。2026H1收入中89.6%在某一时点确认，只有10.4%随时间确认；公司没有披露续费率、净收入留存率、付费用户绝对数或合同承诺期。文中带虚线下划线的词可在文末「名词速查」查阅。

白话解读

这不是“老业务多卖一点”，而是交易方式换了：去年同期约85%的收入来自本地化部署，今年约87%来自云端/API。好消息是云端从亏毛利变成24.6%毛利；坏消息是它仍低于本地化业务，且旧业务毛利率也在下滑，所以集团毛利率被结构性拉低。

收入放大让经营亏损率从−995%看起来改善到−225%，但绝对经营亏损仍扩大。对一家模型公司，真正的下一道门槛不是“收入继续翻倍”，而是新增毛利增长能否快过研发和算力投入。

投资逻辑与核心增长驱动 · 互联网用户与变现 · 新业务转型

API飞轮开始转动，但关键读数仍只有相对增幅

本期最强的多头证据不是GLM在某一张榜单上的排名，而是三个财务结果同时发生：云端/API收入大幅扩张、云端毛利转正、销售营销费用下降。它们共同说明模型能力已开始通过真实调用变现，而不是完全靠定制项目或买量。

24.6%云端毛利率已经证明“调用放大后不必永久亏毛利”；但要形成真正飞轮，毛利还必须覆盖研发、销售、行政、应收风险与资本成本。

客户质量：历史在分散，本期却停止披露

前五大客户收入占比从2023年的61.5%降到2024年的45.5%、2025H1的40.0%，FY2025进一步降至26.51%，最大客户7.90%。这是积极轨迹；但2026H1没有更新集中度。供应侧并未同样轻松：FY2025前五大供应商采购占52.34%，最大供应商20.92%，而本期算力预付款与应付款都显著上升。

最强多头证据

API收入、毛利率和销售费用同时改善，比用户数或榜单更接近可验证商业化。它说明智谱至少已跨过“模型有没有人付费”的门槛。

最强证据缺口

没有绝对token量、付费用户、留存、NRR、Coding收入占比和H1客户集中度。高增长能否重复，仍无法从合同质量和客户队列上验证。

白话解读

把管理层指标看成一张“仪表盘”：几乎所有指针都朝上，但多数只写“比年初多几倍”，没有写底数。低基数可以制造很大的倍数，客户集中也能制造很大的调用增长。财务报表给出的硬确认只有两项：API收入真的来了，API毛利真的转正了；飞轮是否稳定，还要等绝对用户、留存和现金消耗。

当前毛利率下，静态盈亏平衡需要多大规模

把本期研发、销售、行政和减值合计，扣除其他收入，再除以26.4%毛利率，可得到一个约90.9亿元半年收入的静态盈亏平衡门槛，约为本期收入的9.5倍。这不是预测：它假设费用绝对额不再增加、毛利率也不变，只是把当前成本结构翻译成“还差多远”。若云端毛利率向35%—40%提升，门槛会明显下降；若模型竞赛继续抬高研发，门槛则会上升。

白话解读

收入增长像一台突然加速的发动机，但研发是一座更大的山。会计净亏损变小，不等于发动机已推动车子上坡；真正要看的是毛利增加一元时，经营亏损能不能减少一元以上。本期答案仍是否定的。

白话解读

大额配售让公司短期“不缺钱”，但没有让商业模式自动赚钱。现金越多，市场越容易把亏损看成可承受；对股东真正重要的是，这笔钱投入模型和算力后，能否让每股毛利、每股现金流和每股价值增长，而不是只让公司规模增长。

行业与宏观环境 · 竞争对手 · 贝塔与阿尔法

榜单领先很短，成本曲线与真实调用才可能留下来

智谱把技术路线描述为“Chat → Coding → Agent → Co-work → Autonomous AI”。Coding的优势是任务结果容易验证，可为长程规划、工具调用和错误恢复提供反馈；公司希望再把这些能力迁移到网络安全、数据分析和复杂自动化。但2026H1的规模收入主要仍来自开放平台/API，Co-work在法律、金融、教育等行业尚未形成可审计的收入分拆。

pure-play的可能优势

相较拥有云、广告或企业软件业务的科技巨头，独立模型公司与企业客户核心业务冲突更少；云端、本地、端侧和多芯片适配也提高交付灵活性。

真实任务反馈

编码和Agent任务产生可验证轨迹，调用越多，越有机会缩短模型迭代周期。这个机制比一次静态榜单更接近可持续竞争力。

平台对手可以交叉补贴

科技巨头拥有云资源、分发入口和其他业务现金流，可以压低API价格；智谱则同时承担前沿训练和推理服务的资本强度。

开源压低切换成本

模型能力差距可能只维持数月，开源权重和兼容API又让客户迁移更容易。ASP能否穿越下一轮价格战，比本期上调101%更重要。

国产算力：供应安全与成本优势的同一枚硬币

管理层称公司年初实施“All-in-Infra”，已用10万级国产芯片承担推理；GLM-5.3-Flash首次在超大规模真实流量中全面使用国产芯片集群，同硬件基线端到端性能提升3倍，单位token性价比可比主流进口卡。这些都是发行人陈述，尚无第三方生产SLA和单位成本验证。公司也坦承国产芯片内存容量与带宽不足，特别是1M上下文场景仍受限。

白话解读

大模型行业没有一条永久护城河。榜单可以被下一次发布刷新，价格可以被大平台补贴，开源可以缩短追赶。智谱真正能建立的优势只有一条：真实任务更多 → 迭代更快 → 成本更低 → 调用更多。本期只验证了这条链的中间两环，尚未验证长期回报。

公司治理专项 · 管理团队与股权结构 · 股东回报

融资能力很强，少数股东要盯的是每股价值而非公司规模

7月配售后，单一最大股东一致行动集团合计持股约28.58%（未上市股26.43%加H股2.15%），未上市股份占总股本48.22%。董事长刘德兵与CEO张鹏分设，董事会由3名执行、3名非执行和3名独立董事组成；审计委员会形式上多数独立，但联合创始人李涓子作为非执行董事仍在其中。

两个收购，两个完全不同的资本配置问题

北京红钻：实质是买物业

总成本约3.602亿元，标的无实质业务，核心资产是自用物业，并按资产收购入账。这不是AI技术并购；在高现金消耗期，需单独检验物业使用率与替代租赁成本。

中科加禾：战略相关、商誉很高

2.919亿元收购60% AI基础设施研发公司，可识别净资产0.791亿元，却确认2.444亿元商誉，占对价约84%。收入、利润、核心IP、人员留任和业绩承诺均未披露。

短期财务韧性

配售规模远高于现有债务，研发与基础设施55%、业务扩张及并购15%、营运资金与资本结构30%的用途也已披露。

长期治理检验

奖励计划的购买价、绩效目标和部分归属条件可由董事会决定或豁免；每次授予规模、对象、价格和绩效门槛都要逐笔跟踪。

白话解读

公司会不会成功，和现有每一股能拿到多少成功，并不是同一件事。配售、A股、激励和并购都可能让公司更强；但如果新资本的回报低于摊薄幅度，企业价值增加也可能伴随每股价值下降。这正是当前估值最容易忽略的治理问题。

一句话总结

市场不是只在赌“API收入继续增长”，而是在赌它以极高速度增长、毛利继续改善、竞争者没有把倍数压下来、配售资金没有被亏损过快消耗。现价已经进入本报告的牛市路径，基本面只要“很好”还不够，必须“极好且兑现很快”。

风险因素与预警 · 投资验证 · 多空辩论

争论的核心不是增长真假，而是增长能否跑赢资本消耗

“智谱已跨过模型有没有人付费的门槛，但还没跨过每股资本回报能不能成立的门槛。”
多头最强论点

模型能力已经转成真实调用、提价和API毛利转正；国产算力适配与全栈推理优化可能形成“能力—成本—调用”的正反馈。巨额现金又给了公司充分迭代时间。

空头最强论点

市场可能把一次API爆发误当成稳定SaaS。研发是收入223%、应收是半年收入82%，绝对付费用户、留存、H1集中度和现金流都没披露，估值却已资本化极端成功。

最可能的中间情形

收入继续高速增长、云端毛利逐步改善，但研发和算力也持续抬升；公司获得行业地位，股东回报却因估值压缩与新增资本被摊薄。

什么能解决争论

连续两期看到云端毛利向30%—40%移动、调整亏损率下降、应收和算力预付不再快过收入，并开始披露绝对付费和留存。

风险排序

第一是估值风险：即使公司经营很好，倍数压缩也能让股价受损。第二是单位经济：云端毛利还不够覆盖研发。第三是资本配置与摊薄：资金多但回报未验证。竞争、国产算力、客户集中和并购商誉都通过这三条主线传导，不再另列一串通用风险。

最终投资建议与操作方案

中性偏谨慎：认可商业化拐点，不为极端成功预付款

智谱2026H1是基本面意义上的重要转折：API收入、调用、提价和云端毛利共同证明商业化不再停留在概念。但经营与调整亏损仍扩大，现金流缺失，收入质量和客户分散度没有足够绝对数据。按HK$1,195，市场已把接近本报告牛市的路径写进股价，风险收益不对称。

结论：观望，置信度中等。不是因为公司没有增长，而是当前价格没有为增长不及极端预期、终值倍数压缩或规划摊薄留出足够缓冲。未提供组合约束，故不建议仓位、止损或交易区间。

FY2026云端毛利与绝对亏损

毛利率能否稳定高于25%，调整亏损率和绝对额是否下降。

下一份年报付费与留存透明度

绝对付费用户、NRR、客户集中度和应收来源是否恢复披露。

A股推进摊薄与资金用途

监管进度、最终股数、价格和募资现金必须重新进估值桥。

H1 2027经营杠杆复验

新增毛利是否连续快过新增研发与算力成本。

最强反方观点：本报告可能低估了前沿模型商业化的非线性。如果Coding成为企业软件的新入口，调用量、ASP与毛利同时复利，而国产算力显著降低成本，那么220亿元的2028牛市收入也可能显得保守。能推翻本报告谨慎结论的，不是下一次模型发布，而是连续财务期里“云端毛利上升、调整亏损下降、应收正常、绝对付费留存披露”四项同时出现。

基础大模型用海量数据训练、可适配多种任务的通用模型；需要持续研发、训练和推理算力。
MaaSModel as a Service，把模型能力通过云端API、订阅或工具提供给客户，而非让客户从头训练。

Agent / 智能体能规划步骤、调用工具并执行任务的模型应用；比单轮问答更接近业务流程。
Co-work智谱对多智能体协作完成复杂任务的产品路线称呼；当前仍在早期商业化。
云端部署模型运行在服务方云端，客户按调用或订阅付费；本期占收入86.5%。
本地化部署模型安装在客户自己的基础设施，通常涉及实施与验收，收入波动和交付成本更明显。
